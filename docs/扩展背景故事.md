# 帷幕之地 — 扩展背景故事 v3.0

> 在「世界观定稿」的绝望框架下，补全五个角色的完整传记 + 世界观真相的深度交代。
> 核心主线：清醒者 · 入腹 · 空座。所有角色，最终都指向同一个问题——**成神之后，还是你吗？**

## 一、新角色完整传记

### 伊瑟尔 — 暗影织网者

```
帷幕裂隙的边缘，有一座无人居住的废弃石屋。至少，人们以为它无人居住。

伊瑟尔住在那里面，或者更准确地说——她住在所有屋子的缝隙里。
在帷幕之地，如果你有足够的钱或者足够的秘密，
你迟早会找到伊瑟尔。她什么都知道。

"情报贩子"这个称呼是她自己散布出去的。
更准确的说法是：她是一个在诸神黄昏中失去了自己神祇的祭司。
她侍奉的神——阴影与欺骗之主——在帷幕编织时被用来当作"针线"。
她的神被撕碎、拉长、编织进了帷幕的纤维中。

所以伊瑟尔能听到帷幕中的低语。
不是每个人都能听到的"指引"——而是更深的、更古老的、
属于她那位已经被做成针线的神明的碎片。

她来暮色村不是为了玩游戏。
她来是为了收集足够多的秘密，
用秘密编织成线，用线缝补她神明的碎片，
然后——也许——让祂复活。

而她需要的最后一个秘密，
藏在这场游戏中某个人的血液里。
她不知道是谁。所以她观察所有人。

——以上，是她以为的故事。

真相是：她的神早就死了。不是被做成针线，是被吃掉了。
那些"碎片"，是消化之后漏出来的一点渣。
她缝补了这么多年，不是在复活她的神——
是在一针一线地，把屠宰场的围栏，缝得更牢。

而她终有一天会发现这件事。
那一天，就是伊瑟尔成为"清醒者"的时刻。
一个用半辈子缝补牢笼的人，发现自己在帮凶手加固囚室。
```

### 格伦 — 流浪铁匠

```
在矿脉山脉的深处，格伦的家族世世代代为诸神锻造武器。
托尔的雷神之锤，弗雷的神奇宝剑——都出自他们家族之手。

但诸神黄昏后，再没有神来下订单了。

格伦是家族最后一个人。他把铁砧背在背上，
走过整个帷幕之地，为凡人锻造防护装备。
他不收钱——只收"故事"。
因为他说，每一把武器都需要一个故事作为灵魂。

他在暮色村的铁匠铺开张的那天，
一个蚀者试图破门而入。
格伦用铁锤敲碎了蚀者的下巴，
然后把铁砧堵在门口继续打铁。

第二天早上，所有人都来订做门锁加固。
格伦说："我一晚上只能加固一扇门。选谁，你们自己决定。"
于是每晚，村里人都要争论——
谁最值得被保护。
而格伦只是在旁边静静地打铁，
数着门外裂隙共鸣的声音。

他的锤子有一个秘密：
那不是一把普通的铁锤。
那是他家族为托尔锻造雷神之锤时剩下的边角料打的。
虽然不及雷神之锤的万分之一力量，
但在特定的条件下——在被真正需要保护的人手中——
它会发出微弱的雷光。

格伦不知道的是：这微弱雷光，是他家族留在世上的、最后一点还亮着的灵焰。
而他每天为村里人加固的门锁，锁住的从来不是外面的东西。
是里面的人。
```

### 艾琳 — 守墓人

```
骨灰平原——帷幕之地最安静的地方。
这里埋着所有在博弈循环中死去的人。
每局游戏结束，新的尸体被埋进来。
艾琳负责挖坑、填土、刻名字。

她已经做了二十年。二十年来，她见过太多死亡。
追猎者的尸体旁边放着他的枪（但第二天枪就消失了——被新的追猎者取走了）。
草药学者的尸体嘴里塞着最后一片叶子。
蚀者的尸体在月光下化为灰烬。
灵织者的尸体——最普通，也最让人难过。

艾琳不说话。但她什么都记得。
谁的尸体是在哪个位置，谁和谁死在同一天晚上，
谁被背叛了（背后有刀伤），谁为了保护别人而死（挡在门前）。

有一天晚上，她发现了一座新的坟墓。
不是她挖的。墓碑上刻着她的名字——艾琳。

她盯着那个墓碑看了一整夜。
天快亮的时候，她拿起铲子，开始挖。
她想知道自己到底死了没有。

然后她挖到了一具空棺。

空棺里什么都没有。没有尸体，没有骸骨，没有遗物。
只在棺底，用只有她能读懂的方式，刻着一句话：

"这里本该是你成神之后的位置。但神位，已经没了。"

从此之后，艾琳每晚都到南山墓地来。
不是为了守墓——是为了等那个给她挖坟的人。

可她等了二十年，渐渐明白了：
没有人给她挖过坟。
那座空坟，一直都在那里，等着每一个人。
因为每一个玩这场游戏的人，最后都会走到这具空棺前——
发现里面，从始至终，都是空的。
```

### 奥里克 — 疾风信使

```
大瘟疫那年，奥里克十七岁。

瘟疫从一个村子传到另一个村子。
帷幕之地的所有草药学者都被隔离了——人们害怕。
没有药，没有医生，没有希望。

奥里克说："我去拿药。"
没有人相信他。
从暮色村到帷幕裂隙，来回六十里。
中间要穿过蚀者群的领地、沼泽、废墟。
而奥里克只是一个跑得快一点的农家少年。

他用了两天两夜跑完全程。
第三天黎明，他满身泥泞地出现在村口，
手里抱着药瓶——但药瓶是空的。
在路上摔碎了一个，被蚀者追时丢了一个。
最后只有一个完整的。
只能救一个人。

他选了村里最年轻的女孩——一个五岁的孩子。
其他十三个人在那年冬天死了。
包括他自己的母亲。

事后有人问他："你后悔吗？只救了一个人？"
奥里克说："我后悔没能跑得更快。"

从那以后，他每天都在跑。
跑得更快、更远、更久。
不是为了弥补什么——他自己也说不清。
只是每当他想停下来的时候，
就会听到母亲在那一晚对他说的话：
"去。别管我。去。"

所以现在在暮色村，
当夜幕降临，蚀者出没，
奥里克是唯一一个能在村子里自由奔跑的人。
他的速度是他的武器，他的耐力是他的盾牌。
他会把消息送到每一个需要的人手中。
他不会让那一年重演。

——他不会让那一年重演。
这是奥里克给自己讲的故事。

真相是：无论他跑得多快，消息送到得多及时，
那十三个人的死，都不会改变。
因为那年冬天会死的人，和今年冬天会死的人，
都写在同一张、他永远读不懂的名单上。
奥里克的悲剧，不是"没能跑得更快"。
是他至今仍相信，只要跑得够快，就能跑赢饥饿。
```

### 奈莉亚 — 帷幕学者

```
观测塔废墟位于帷幕之地最高的山丘上。
三十年前，奈莉亚来到这里时，塔已经塌了一半。
但另一半——朝向帷幕的那一半——完好无损。

她花了三十年，用唯一的眼睛（另一只在一次"近距离观测"中失明了）
观测帷幕的每一道波纹、每一次闪烁、每一次颜色变化。

她的结论是：帷幕不是静止的。它在呼吸。
它在一吸……一呼……一吸……一呼……
每次呼吸的周期，大约是现实中一局游戏的长度。

后来，她修正了自己的结论：
那不是呼吸。那是咀嚼。

她发现帷幕最"活跃"的时刻——不是血月之夜，不是午夜——
而是当游戏中的"背叛"发生时。
当一个玩家投票出局了自己的同伴。
当一个蚀者刀掉了曾经信任自己的人。
当一个守卫没有保护该保护的人，而是在保护自己。

这些背叛——这些"道德破裂"的瞬间——
会在帷幕上激起涟漪。
而这些涟漪，会被帷幕之外的"东西"感知到。

准确地说，不是"感知到"。
是"尝到"。

奈莉亚试图警告所有人。但没有人相信她。
所以她自己来了暮色村。
她不信任任何所谓"指引"。
她知道在"指引"背后有某种意志。

她来找出真相。
她来记录一切。
然后——如果必要的话——
她来亲手撕开帷幕，看看外面到底是什么。

而奈莉亚不知道的是：
她是十五个被标记的人里，离真相最近的一个。
也是"它"最想让她活下去、最想让她慢慢看见的那一个。
因为一个终于看清一切、却什么也做不了的人，
他死前的那份绝望，是全天下最肥美的灵焰。
```

## 二、世界观真相 · 深度交代

### 2.1 帷幕的运作原理（真相版）

```
凡人以为，帷幕是一堵"墙"，挡住外面的怪物。

真相是：帷幕是一个"围栏"，圈住里面的食物。

它的运作，是这样的：

1. 诸神被引导着，把自己织成帷幕——他们以为这是牺牲，实则是被送上屠场
2. 帷幕挡住的，从来不是"它"。"它"本来就不需要进来
3. 帷幕真正的作用，是把凡人圈在一片封闭的世界里，
   让恐惧、背叛、牺牲、死亡，在这里自然而然地发生
4. 每一份死亡与背叛释放出的灵焰，都通过帷幕，流向"它"
5. 而"指引"——那个组织游戏的东西——负责确保：
   总有人在对立，总有恐惧被产生，总有背叛发生
6. 这不是循环，不是测试，不是任何有"意义"的东西
   这只是……进食
7. 所以没有赢家。你赢，它吃你的胜利；你输，它吃你的失败
   你背叛，它吃你的愧疚；你守护，它吃你的牺牲
```

### 2.2 诸神黄昏的真正原因（真相版）

```
表面上：众神联手对抗帷幕之外的古老存在，全部战死。

真相：众神不是战死的。他们是被吃的。

过程是这样的：

当"它"开始入侵时，众神发现了一个事实：
他们打不赢。"它"不能被杀死，因为它没有可以被杀死的东西。
它没有灵焰，没有心脏，没有致命点。它不是活的——它只是"在了"。
而你越攻击它，它越懂你。它越懂你，它就越存在于你之中。

于是众神陷入绝境。

而"它"在这个绝境里，做了唯一一件"仁慈"的事——
它把一个念头，放进了诸神的脑海里，像是一个他们自己想到的、高尚无比的主意：

"我们把自己织成一道帷幕吧。挡住它，保护凡人。"

诸神至死都以为，这是他们的集体抉择，是牺牲，是崇高。
他们没有意识到——想让人心甘情愿地走向屠场，
最好的办法，就是让他以为自己正走向神坛。

所以诸神"献祭"了。
他们把自己织进了帷幕。
然后，他们成了"它"的第一道菜。

一万年来，"它"一直在慢慢消化他们。
而帷幕之内，凡人抬头，看见天空还在，大地还在，
以为诸神还在守护他们。
```

### 2.3 千面之影（真相版）

```
凡人以为，千面之影是帷幕之外最古老、最可怕的存在之一。
它没有固定的形态——它以人类的恐惧为镜子。
你怕什么，它看起来就像什么。

真相是：千面之影不是"它"本身。它只是"它"伸进帷幕里的一只手。

它的"目标"，凡人以为是毁灭，是寄生。
其实更简单：它在挑选。

它在每一局游戏中挑选一个"容器"——
一个精神最脆弱的玩家。
通过微妙的引导（在指引中插入偏差的低语），
它试图让这个玩家做出最糟糕的选择：
背叛同伴、抛弃责任、自保至上。

如果被选中的容器在游戏结束时存活，
并且做出了"不道德"的选择（由系统根据投票/行动判断），
那么千面之影就在这个容器中埋下了一颗种子。
累积三颗种子的玩家……开始发生变化。
他们的眼睛在夜晚偶尔闪烁。
他们听到更多低语。
他们开始觉得——也许外面的东西没有那么可怕。
也许它们只是饿了。

——它挑选这些"容器"，不是因为恨他们，也不是因为爱。
是因为一个内心充满恐惧与挣扎的人，他死前的灵焰，
会烧得最旺，也最……好吃。
```

## 三、关键物品扩展描述

### 西格德的猎枪

```
枪托上刻着十二条刻痕——每一道代表一个被这把枪杀死的蚀者。
枪管微弯——在近身肉搏中被一个冥僧人咬弯的。
但那颗子弹还是射出去了。又添了一道刻痕。

西格德从来不擦它。他说血迹是猎枪最好的润滑油。

枪托底部镶着一小片龙骨——
来自他父亲齐格弗里德杀死的那条龙。
所以这把枪在打蚀者时，偶尔会发出龙吼般的巨响。
不是因为任何魔法。
只是龙骨的残留意志——对"野兽"的永恒厌恶。

而西格德不知道的是：
那片龙骨的灵焰，也在一分一分地、被这把枪的主人一点点磨掉。
每一道刻痕，都是一次"你离当初那个想屠龙的人，又远了一步"。
```

### 哈尔瓦德的缚链

```
这不是一条项链。这是一个项圈。
哈尔瓦德在十二岁那年自己给自己戴上的。
他知道自己体内有什么。
他知道月圆之夜会发生什么。

缚链的内侧刻着一段文字——他母亲在他戴上之前刻下的：
"记住你是一个人。不是因为你没有獠牙，而是因为你能选择不咬人。"

缚链在哈尔瓦德蚀变时依然挂在脖子上。
它不会断——因为它不是靠物理强度拴住他的。
它靠的是他对那个十二岁小男孩的记忆——
那个还没经历过第一次蚀变，
还没有在清晨发现手上沾血的男孩。

如果有一天哈尔瓦德彻底放弃了人性，
缚链会自动断裂。
目前为止，它还挂着。

——但"它"很有耐心。"它"不急着让缚链断。
"它"想看：一个明明已经被消化了一半的人，
要花多少年，才会自己摘下自己的项圈。
```

### 布丽吉德的火把

```
这不是一根普通的火把。
它的燃料不是油、不是木材、不是任何可以耗尽的东西。
它的燃料是——希望。

每次有人在绝境中选择保护他人而非自保，
火把就更亮一点。
每次有人在黑暗中选择说出真相而非沉默，
火焰就更高一点。
每次有人在可以逃跑的时候选择留下，
火就不会熄灭。

相反，每次有人为了自保而出卖同伴，
每次有人在投票中说谎以保护自己，
每次有人放弃抵抗——
火焰就暗一点。

布丽吉德不知道这个机制。
她只知道有时候火焰会毫无原因地变弱——
然后她会在第二天发现某人在投票中背叛了阵营。
她开始怀疑这两者之间的关联。
但还不敢确认。

她不知道的是：那根火把，烧的从来不是"希望"。
烧的是持火人自己。
每亮一分，她就离熄灭，近一分。
```

## 四、叙事使用指南

这些故事不是一次性读完的背景材料。
游戏应该**分阶段揭示**——而且，越到后面，越接近真相。

### 阶段一：选人时
展示角色的标题和一句话简介（代码已有，`getShortDescription()`）
——这一层，全是"凡人所信的故事"。

### 阶段二：序幕
展示世界观的简短段落（代码已有，`generatePrologue()`）
——这一层，已经埋下了"帷幕是锅"的第一颗钉子。

### 阶段三：游戏进行中
- 玩家在3D地图中拾取"叙事碎片"时，解锁相关角色的背景段落
- 在特定地标处触发"回声低语"——已死角色的台词语音
- **蚀者阵营**的玩家，会额外听到"指引"背后的、更低沉的一层低语

### 阶段四：游戏结束后
- 展示本局所有玩家的角色卡（含背景故事）
- 玩家的个人叙事总结（代码已有，`getPersonalNarrativeSummary()`）
- 如果解锁了隐藏关系或特殊成就，展示额外叙事
- **无论胜负**，结算画面的最后，都压着同一句沉默

### 阶段五：长期
- 玩家收集的叙事碎片可在"图鉴"中回顾
- 收集全部碎片，解锁世界观"真相文档"（即《世界观定稿》卷八·全貌）
- 累计3局"背叛"行为 → 解锁千面之影相关叙事
- 累计5局"合作"行为 → 解锁"合流"结局相关叙事（绝望版）
- 累计10局无论胜负 → 解锁"清醒者"主案结局的钥匙碎片

> 设计原则：**真相永远只差最后一块碎片。** 让玩家在一次次"差一点看清"中，自己拼出那个他们其实已经猜到了、却一直不敢承认的答案。
